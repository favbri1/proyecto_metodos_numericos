Simulación Numérica de Abastecimiento, Precios y Conflicto Social

Contexto del problema real

En el contexto actual de crisis, enfrentamos problemas críticos de abastecimiento de carburantes, fluctuación de precios de alimentos y conflictos sociales. Este proyecto interactivo utiliza modelos matemáticos computacionales para entender y predecir estos fenómenos, demostrando cómo los métodos numéricos son el mejor aliado para la toma de decisiones estratégicas.

Objetivos Generales

  • Aplicar Sistemas de Ecuaciones Lineales para optimizar redes de transporte.
  • Utilizar Raíces de Ecuaciones para hallar umbrales críticos de abastecimiento.
  • Reconstruir curvas de precios con datos dispersos mediante Interpolación.
  • Calcular costos acumulados y pérdida de poder adquisitivo usando Integración Numérica.
  • Simular el vaciado de reservas y dinámica social con Ecuaciones Diferenciales Ordinarias (EDO).

Conclusiones Finales

¿Qué se aprendió?

Se demostró que la crisis social y de abastecimiento no es un evento aleatorio; puede modelarse matemáticamente para anticipar puntos de quiebre (Raíces), costos acumulados de inflación (Integración) y el colapso logístico (Sistemas Lineales y EDOs).

¿Qué método fue más útil?

Las Ecuaciones Diferenciales (RK4) resultaron vitales para modelar escenarios dinámicos continuos, como el vaciado de reservas y la rápida propagación del pánico y descontento social (Escenarios B y G).

Limitaciones del modelo

Los modelos matemáticos (como la interpolación de Lagrange) pueden sufrir de sobreajuste si los datos de precios varían por rumores falsos (Sistemas mal condicionados - Escenario F), mostrando oscilaciones poco reales (Fenómeno de Runge).

Mejoras a implementar

Se podría vincular la página a una API de datos en tiempo real de mercados y estaciones de servicio, permitiendo que los métodos numéricos procesen datos vivos utilizando Splines Cúbicos para la interpolación, garantizando curvas más suaves.
